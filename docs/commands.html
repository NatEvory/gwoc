init

Create a new bare repo hub with a primary worktree.

usage
gwoc init <name> [--dir <path>] [--branch <name>] [--primary <name>] [--flat] [--force] [--no-hooks]
flagdefaultdescription
--dir <path>cwdDirectory to create the hub root in
--branch <name>mainDefault branch name
--primary <name>branch namePrimary worktree directory name
--flatfalsePlace the bare repo and worktree directly in --dir (no <name>/ hub root)
--forcefalseAllow creating a hub inside an existing git repo
--no-hooksfalseSkip post-init hooks

Creates <dir>/<name>/ (hub root) containing <name>.git (bare repo) plus the primary worktree on the default branch. An existing empty <name>/ directory is reused; a non-empty one is refused. With --flat everything lands directly in --dir (the pre-0.15 layout). Refuses to run inside an existing git repo unless --force is passed.

clone

Clone a remote repo into a bare hub with a primary worktree.

usage
gwoc clone <url> [name] [--dir <path>] [--primary <name>] [--flat] [--force] [--no-hooks]
flagdefaultdescription
[name]derived from URLHub name
--dir <path>cwdDirectory to create the hub root in
--primary <name>default branch namePrimary worktree directory name
--flatfalsePlace the bare repo and worktree directly in --dir (no <name>/ hub root)
--forcefalseAllow cloning into a directory inside an existing git repo
--no-hooksfalseSkip post-clone hooks

Creates <dir>/<name>/ as the hub root, clones into a bare repo inside it, then adds a primary worktree on the default branch. Configures the standard fetch refspec and runs an initial fetch, so the hub tracks origin: branches pushed after the clone stay discoverable via fetch, checkout, and sync.

new

Create a new worktree on a new branch.

usage
gwoc new <slug> [--branch <name>] [--no-hooks]
flagdefaultdescription
--branch <name>repo default branchBase branch for the new worktree
--no-hooksfalseSkip post-create hooks

Creates <hub-root>/<slug>/ with a new branch named <slug> based off the given base branch.

checkout alias: co

Check out an existing local or remote branch into a new worktree.

usage
gwoc checkout <branch> [--no-fetch] [--no-hooks]
flagdefaultdescription
--no-fetchfalseSkip the upfront git fetch --all --prune
--no-hooksfalseSkip post-create hooks

Slug equals the branch name verbatim, so slashes nest: user/pr-123 lands at <hub>/user/pr-123. Resolution order after the fetch:

  1. A local branch exists: check it out and wire its upstream to origin/<branch> when the remote-tracking ref exists.
  2. Exactly one remote has the branch: create a local tracking branch.
  3. Multiple remotes have it: prefer origin, otherwise error.
  4. Not found anywhere: error.

Errors if the worktree path is taken or the branch is already checked out in another worktree.

merge

Merge a worktree branch into the primary worktree.

usage
gwoc merge <slug> [--into <branch>]
flagdefaultdescription
--into <branch>current branch in primaryTarget branch to merge into

Targets the worktree that currently has <branch> checked out, falling back to the primary worktree. Refuses if the target worktree has uncommitted changes.

rebase

Rebase a worktree branch onto the latest target branch.

usage
gwoc rebase <slug> [--onto <branch>] [--no-fetch]
flagdefaultdescription
--onto <branch>default branchBranch to rebase onto
--no-fetchfalseSkip fetching before rebase

Fetches from origin first (skipped automatically when no remote is configured). Refuses on uncommitted changes. The rebase runs inside the worktree directory, so conflicts are resolved right there.

sync

Fetch the default branch and update every live worktree in one command.

usage
gwoc sync [--remote <name>] [--no-fetch] [--merge] [--stop-on-conflict]
flagdefaultdescription
--remote <name>originRemote to fetch from
--no-fetchfalseSkip the upfront fetch
--mergefalseUse git merge instead of git rebase on feature worktrees
--stop-on-conflictfalseOn conflict, stop mid-rebase in that worktree and exit non-zero

Walks every live worktree: the default-branch worktree fast-forwards to the remote; feature worktrees rebase (or merge) onto it. Dirty trees, detached HEADs, and in-progress rebases are skipped. Conflicts auto-abort by default, restoring the pre-sync state, and are listed at the end; --stop-on-conflict leaves the worktree mid-rebase for manual resolution instead.

list alias: ls

List all worktrees in the hub: path, HEAD commit, and branch. No flags.

usage
gwoc list

status

Show worktree info: branch, file changes, remote tracking, last commit. With no slug, reports every worktree. Warns on slug/branch mismatches and detached HEADs.

usage
gwoc status [slug]

doctor alias: check

Run health checks on the hub.

usage
gwoc doctor [--merged] [--fix]
flagdefaultdescription
--mergedfalseAlso list orphan branches already merged into default
--fixfalseInteractively fix issues with safe automatic repairs

Per-worktree checks: slug/branch mismatch, detached HEAD, upstream gone. Hub-wide checks: orphan branches, prunable worktree entries, missing primary worktree. Exits non-zero when issues are found. --fix walks each issue with a prompt: prune stale entries, rename mismatched directories, unset gone upstreams, and delete orphan branches (unmerged ones get a per-branch confirm that defaults to no).

prune

Prune stale worktree references from the bare repo: cleans up entries for worktrees that no longer exist on disk. No flags.

usage
gwoc prune

manage alias: ui

Interactive worktree manager: an arrow-key picker for selecting a worktree and an action (status, rename, rm, merge, push, pull, rebase, new). Esc cancels at any level. Requires a real TTY.

usage
gwoc manage

completion

Print a shell completion script. Completes subcommands, and worktree slugs for slug-taking commands.

install
# bash, in ~/.bashrc
eval "$(gwoc completion bash)"

# zsh, in ~/.zshrc after compinit
eval "$(gwoc completion zsh)"

# fish, in ~/.config/fish/config.fish
gwoc completion fish | source

info commands

Path and metadata printers, handy for scripting (e.g. cd "$(gwoc primary)").

usage
gwoc root         # hub root directory (parent of the bare repo)
gwoc dir          # bare repo path (<name>.git)
gwoc primary      # primary worktree path
gwoc path <slug>  # worktree path for a slug
gwoc default      # default branch name

global options & hooks

Every command accepts -h/--help. Commands that operate on a hub work from anywhere inside it: the hub root, any worktree at any depth, or other hub subdirectories. From an unrelated git repo they refuse; override with --git-dir <path> or the GWOC_GIT_DIR environment variable. rm and rename refuse to operate on the worktree your shell is standing in.

init, clone, new, and checkout run optional hook scripts after creating a worktree (post-init, post-clone, post-create). Every matching hook runs, in order:

hook lookup order
1. ~/.config/gwoc/hooks/<name>        # user level (honors XDG_CONFIG_HOME)
2. <hub-root>/.gwoc/hooks/<name>      # hub level
3. <worktree>/.gwoc/hooks/<name>      # worktree level

Skip hooks per invocation with --no-hooks. Requires git ≥ 2.35.0.
